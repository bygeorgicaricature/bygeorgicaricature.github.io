BYGEORGI SITE — КАЧВАНЕ В GITHUB PAGES

1. Създайте ново repository, например: bygeorgi-links
2. Качете ВСИЧКИ файлове и папката assets в основната директория.
3. Отворете Settings → Pages.
4. Под Build and deployment изберете:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Натиснете Save.
6. След 1–3 минути страницата ще бъде на адрес:
   https://<вашето-потребителско-име>.github.io/bygeorgi-links/

Важно:
- Не преименувайте index.html.
- Папката assets трябва да остане със същото име.
- Facebook линкът е постоянният: https://www.facebook.com/bygeorgi.art
